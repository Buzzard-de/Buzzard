GitHub Pages Deployment

1. Projektordner öffnen

Öffne PowerShell und wechsle in deinen Projektordner:

cd C:\Users\yanli\buzzard

2. Skript starten

Starte das Publish-Skript mit dem Wrapper, damit PowerShell-Skripte erlaubt sind:

.\repo\publish-github.cmd

Oder direkt:

powershell -NoProfile -ExecutionPolicy Bypass -File .\repo\publish-github.ps1

3. Eingaben machen

Wenn das Skript fragt, gib ein:

  • Deinen GitHub-PAT
  • Den Repo-Pfad: Buzzard/buzzard
Tipp: Erstelle den PAT auf GitHub unter Settings → Developer settings → Personal access tokens mit mindestens repo oder contents: read und pages: write.

4. Ergebnis

Das Skript:

  • erstellt das Repo auf GitHub
  • setzt es auf public
  • legt den GitHub Pages Workflow an
  • pusht deine Website nach main
