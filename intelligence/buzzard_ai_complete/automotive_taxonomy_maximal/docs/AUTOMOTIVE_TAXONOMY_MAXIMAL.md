# Buzzard Automotive Taxonomy – Maximum Vehicle-Need Architecture

The taxonomy is built around one principle:

**What can a vehicle need?**

Not a flat product list.

Hierarchy:
Vehicle domain
→ vehicle system
→ component group
→ component type
→ product
→ exact vehicle fitment

Examples:

Automotive
→ Brake System
→ Brake Pads
→ Front Brake Pads
→ Vehicle/axle-specific product
→ Make → Model → Generation → Year → Engine → Engine Code

Automotive
→ Engine
→ Piston System
→ Pistons
→ Engine-code-specific piston
→ exact vehicle fitment

Automotive
→ Fluids & Lubricants
→ Transmission Oils
→ ATF
→ specification/viscosity
→ compatible transmission/vehicle

The system supports:
- passenger cars
- commercial vans
- trucks
- buses
- trailers
- motorcycles/scooters
- ATVs/quads
- tractors/agricultural machines
- classic/oldtimer vehicles
- EVs
- hybrids

Compatibility dimensions:
make, model, generation, year, engine, engine code, fuel, power,
drivetrain, transmission, body, axle and position.

Production connectors are designed for licensed TecDoc, OEM catalogs,
supplier API/XML feeds and Buzzard-verified product data.
