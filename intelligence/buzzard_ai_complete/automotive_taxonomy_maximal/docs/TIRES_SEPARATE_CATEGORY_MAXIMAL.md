# Lastikler – Ayrı Otomotiv Kategorisi

Lastikler are a dedicated top-level category inside Automotive, not merely a
sub-product under Wheels.

Hierarchy:
Otomotiv
→ Lastikler
→ Araç Tipi
→ Alt Kategori
→ Alt-Alt Kategori
→ Ölçü / Teknik Özellik
→ Ürün
→ Araç Uyumluluğu

Vehicle coverage:
Passenger car, SUV/4x4, light commercial, truck, bus, trailer/caravan,
motorcycle, scooter, ATV/quad, tractor, agricultural machines,
construction/industrial machines, racing, classic/oldtimer, EV and hybrid.

Core tire dimensions:
width, aspect ratio, rim diameter, load index, speed index, season,
run-flat, XL/reinforced, EV optimization, M+S, 3PMSF, axle, position,
DOT, OE marking and usage.

The category is designed to work with PIM, vehicle fitment and category
intelligence systems.
