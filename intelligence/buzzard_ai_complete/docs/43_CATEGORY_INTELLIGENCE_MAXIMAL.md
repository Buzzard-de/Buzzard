# BUZZARD 43 CATEGORY INTELLIGENCE MAXIMAL

43 specialized Category Intelligence AI agents monitor their own category while
sharing one intelligence fabric.

## Features

- Public competitor seller monitoring (policy-gated)
- Price history and seller comparison
- Taxonomy discovery and gap detection
- Product assortment gap detection
- Evidence store and change history
- Opportunity scoring
- Shared memory, event bus, Council bridge
- Configurable monitoring schedule

## CLI

```bash
cd intelligence
python3 main.py complete-category-intelligence-43-health
python3 main.py complete-category-intelligence-43-agents
python3 main.py complete-category-intelligence-43-demo
python3 main.py complete-category-intelligence-43-schema
python3 main.py complete-category-intelligence-43-docs
```
