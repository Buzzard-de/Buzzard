# Buzzard AI Phone – Go Live
Software is telephony-integration-ready. To activate real calls:
1. Acquire a business phone number from a telephony/SIP provider.
2. Configure signed inbound webhooks and bidirectional media streaming.
3. Put provider credentials in a secret manager.
4. Configure public webhook/media URLs.
5. Configure the human handoff destination.
6. Configure the realtime speech/AI provider.
7. Test inbound call → audio → AI → audio.
8. Test barge-in, language switching, product/order lookup, verified memory, transfer and error recovery.
9. Complete security, privacy and load tests before production.
