# Buzzard AI v2

This package keeps the existing Doğu Bey intelligence core and adds the next connected layer: Aslan Bey orchestration, Esat Bey defensive scanning, versioned memory, research observations/change detection, optional LLM provider status, API authorization, and health monitoring.

External LLM/search providers are deliberately optional. Configure them through environment variables; the core does not contain hard-coded secrets.
