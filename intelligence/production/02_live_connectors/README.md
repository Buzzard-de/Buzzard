# Live Connectors

Produktionszugang nur über autorisierte Quellen:
- eBay Browse API
- Amazon Creators API
- Google Ads API
- Google Trends / zulässige öffentliche Recherche
- Supplier APIs/XML/CSV
- TecDoc über gültige Lizenz/Zugang
- weitere ausdrücklich erlaubte Marketplace-/Hersteller-APIs

Jeder Connector benötigt Credentials, Rate-Limit-Regeln, Fehlerbehandlung,
Quellen-URL/ID und Zeitstempel. Secrets gehören ausschließlich in Secret Storage.
