# Monitoring Alerts

Der Agent soll alarmieren bei:
- ungewöhnlicher Preisänderung
- starkem Rabatt
- neuer Kategorie
- neuem Produktcluster
- ungewöhnlichem Produktwachstum
- Verfügbarkeitsänderung
- sichtbarem Bestseller/Featured-Signal
- neuem Wettbewerber
- Wettbewerber betritt neue Kategorie
- relevante Marke taucht neu auf
- Datenquelle fällt aus
- Quelle wird veraltet
- API-Limit/Fehler
- widersprüchlichen Beobachtungen

Jede Meldung enthält Quelle, Zeitpunkt, Beobachtung und Konfidenz.
